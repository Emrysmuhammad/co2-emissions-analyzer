# Global CO2 Emissions Analyzer

A Python command-line tool that downloads the Our World in Data CO2 dataset (emissions for more than 200 countries from 1750 to today), analyzes it with pandas, and produces rankings, country profiles, comparison charts and a complete HTML report.

## Questions it answers

- Who emits the most CO2, in total and per person?
- Which countries are historically responsible for the most emissions?
- Which countries have cut emissions the most, and which are growing fastest?
- Which large emitters have already passed their peak?
- Can a country grow its economy while cutting emissions?
- How closely are income and emissions per person linked?
- Which fuels produce the world's emissions?

## Quick start

```bash
git clone <repository-url>
cd co2-emissions-analysis
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py report --open
```

On macOS or Linux, activate the environment with `source venv/bin/activate`. The dataset (about 14 MB) is downloaded automatically the first time a command needs it.

## Commands

```bash
python main.py top -n 5
python main.py top --metric co2_per_capita
python main.py country brazil
python main.py compare usa china india --metric co2_per_capita
python main.py report --open
python main.py download --force
```

Country names are case-insensitive, ISO codes such as `USA` or `GBR` work, and a typo gets a suggestion:

```
> python main.py country Germny
Error: Unknown country 'Germny'. Did you mean: Germany?
```

Example output:


## How it works

- `emissions/download.py` fetches the dataset and writes it atomically, so an interrupted download never leaves a broken file.
- `emissions/loader.py` loads only the needed columns, removes duplicates, separates countries from aggregates such as World, continents and income groups, and resolves country names and ISO codes.
- `emissions/rankings.py` ranks countries by total, per person and cumulative emissions.
- `emissions/trends.py` finds the biggest increases and cuts, countries past their peak, countries that grew their economy while cutting emissions, the fuel mix, and the income and emissions correlation.
- `emissions/charts.py` and `emissions/insight_charts.py` draw the charts with matplotlib.
- `emissions/report.py` combines every analysis into a single HTML report.
- `emissions/profile.py` builds the country profiles, and `main.py` ties everything into the command line.

## Tests

```bash
python -m pytest
```

The 33 tests run on a small synthetic dataset, so they need no download and finish in under a second.

## Data

[Our World in Data CO2 dataset](https://github.com/owid/co2-data), built on Global Carbon Project data. Emissions are fossil CO2 in million tonnes (Mt) and exclude land-use change. Country rankings exclude aggregates such as World, continents and income groups. Figures change as the dataset is updated.
